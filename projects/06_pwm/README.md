# Project 6: PWM (Pulse Width Modulation)

## Objective
Learn to use hardware timers in PWM mode to control LED brightness, understand duty cycle, and create a breathing LED effect.

## Hardware Required (PicsimLab)
- Arduino Uno board
- 1 LED (Spare Parts → Outputs → output_LEDs)

## Key Concepts
- PWM (Pulse Width Modulation) concept
- PWM-capable pins (OC0A, OC0B, OC2A, OC2B)
- Timer PWM modes (Fast PWM, Phase Correct PWM)
- OCR (Output Compare Register) for duty cycle control
- Duty cycle and frequency calculation
- Breathing effect by ramping duty cycle
- Non-inverting vs inverting PWM modes

## How to Build
```bash
make
```

## How to Run in PicsimLab

1. Open PicsimLab main board window (Arduino Uno)
2. Open Spare Parts window
3. Add LED from Spare Parts → Outputs
4. Right-click LED board → Properties
5. **Important**: Configure LED to PD6/6 (PWM-capable pin, not PB5/13)
6. In main window: File → Load Hex → select main.hex
7. Tools → Arduino Bootloader
8. Click Run button
9. LED will smoothly fade in and out (breathing effect, ~5 second cycle)

## Code Explanation

### PWM-Capable Pin Selection
```c
#define LED_PIN 6  // PD6 (OC0A - Timer0 PWM output)
```
- Not all pins support hardware PWM
- PD6 is OC0A (Output Compare 0A) connected to Timer0
- Other PWM pins on Arduino Uno: PD5 (OC0B), PD3 (OC2B), PB3 (OC2A)
- PB5 (D13) does NOT support hardware PWM

### Timer0 PWM Configuration
```c
TCCR0A = (1 << COM0A1) | (1 << WGM01) | (1 << WGM00);
TCCR0B = (1 << CS01) | (1 << CS00);
```

**TCCR0A - Control Register A**:
- `COM0A1`: Compare Output Mode for Channel A
  - Set to 1 = non-inverting PWM mode
  - When timer < OCR0A: output HIGH
  - When timer >= OCR0A: output LOW
- `WGM01` and `WGM00`: Waveform Generation Mode
  - Both set = Fast PWM mode
  - Timer counts 0 → 255, then overflows to 0

**TCCR0B - Control Register B**:
- `CS01` and `CS00`: Clock Select (prescaler)
  - CS01=1, CS00=1 = prescaler 64
  - Timer clock = 16MHz / 64 = 250 kHz
  - PWM frequency = 250kHz / 256 = 976 Hz

### PWM Duty Cycle Control
```c
OCR0A = brightness;
```
- OCR0A = Output Compare Register A
- Sets the duty cycle (0-255 for 8-bit timer)
- How it works:
  - Timer counts 0 → 255 repeatedly
  - When timer < OCR0A: output HIGH
  - When timer >= OCR0A: output LOW
- OCR0A = 0: 0% duty cycle (LED off)
- OCR0A = 127: 50% duty cycle (LED half brightness)
- OCR0A = 255: 100% duty cycle (LED full brightness)

### Breathing Effect Logic
```c
uint8_t brightness = 0;
int8_t direction = 1;

while (1) {
    OCR0A = brightness;
    
    brightness += direction;
    
    if (brightness >= 255) {
        direction = -1;
    } else if (brightness <= 0) {
        direction = 1;
    }
    
    _delay_ms(10);
}
```
- Ramps brightness from 0 to 255, then back to 0
- At max (255), reverses direction to fade out
- At min (0), reverses direction to fade in
- 10ms delay between steps
- Cycle: ~5.1 seconds (2.55s fade in + 2.55s fade out)

## PWM Concept

### What is PWM?

PWM varies the width of pulses in a fixed-frequency square wave:

```
50% Duty Cycle:
    ____    ____    ____
___|    |__|    |__|    |___
    ON  OFF ON  OFF

25% Duty Cycle:
    _    _    _
___| |__| |__| |_________
    ON OFF ON OFF
```

### Duty Cycle = Brightness

- Duty cycle = percentage of time signal is HIGH
- LED brightness is proportional to duty cycle
- Eye averages rapid on/off, perceives varying brightness

### PWM Frequency Calculation

```
CPU Clock: 16 MHz
Prescaler: 64
Timer Clock: 16,000,000 / 64 = 250 kHz
Timer Range: 0-255 (256 counts)
PWM Frequency: 250,000 / 256 = 976 Hz
```

976 Hz is fast enough that LED appears smoothly dimmed, not flickering.

## Why PD6 Instead of PB5?

- PB5 (D13) = no hardware PWM capability
- PD6 (D6) = OC0A = Timer0 Channel A PWM output
- PWM is generated by timer hardware, not software
- Without PWM pin, you'd need software PWM (CPU-intensive bit-banging)

## Learnings

- PWM requires special pins (OC0A, OC0B, OC2A, OC2B on Arduino Uno)
- Timer modes: Normal, CTC, Phase Correct PWM, Fast PWM
- Fast PWM: counts 0→255→0 (fast, simple)
- Phase Correct PWM: counts 0→255→0 (more symmetric)
- OCR register sets duty cycle (0-255 for 8-bit timers)
- Duty cycle = (OCR / 255) × 100%
- Prescaler controls PWM frequency
- Hardware PWM runs automatically (no CPU needed)
- Breathing effect = ramping duty cycle up and down
- Non-inverting mode: HIGH when timer < OCR
- Inverting mode: LOW when timer < OCR
- PWM is used for LED dimming, motor speed, servo control, audio

## Troubleshooting

### LED not dimming
- Verify LED is on PWM-capable pin (PD6/6, not PB5/13)
- Check TCCR0A has WGM bits set (Fast PWM mode)
- Ensure TCCR0B has prescaler bits set (not 0)
- Verify OCR0A is actually changing (use variable watch)

### LED always on or always off
- Check OCR0A value (0 = off, 255 = on)
- Verify COM0A1 bit is set (enables PWM output)
- Ensure LED pin is configured as output (DDRD bit 6)

### No breathing effect
- Verify brightness variable is updating
- Check direction variable toggles at boundaries
- Ensure _delay_ms(10) is present
- Check for overflow in brightness variable

### Flickering LED
- PWM frequency too low (increase prescaler)
- Check that Timer0 is in Fast PWM mode
- Verify CPU clock is 16MHz

### Wrong pin selection
- Remember: only OC0A, OC0B, OC2A, OC2B support hardware PWM
- Arduino Uno PWM pins: D3, D5, D6, D9, D10, D11
- D13 (PB5) does NOT support PWM
